# 교사·학생 사용 안내

## 점수의 기준과 근거

교사 **분석 대시보드 → 기준별 언어 표현**에서 기준 이름 또는 막대를 누릅니다. 발화별 기록 안의 막대도 같은 방식으로 작동합니다.

- 교사가 그 활동에 저장한 평가 기준의 설명을 표시합니다. 예전 기록은 당시 기준을 유지합니다.
- 0점: 근거 없음, 1점: 막연함, 2점: 명시된 단서, 3점: 여러 구체적 단서, 4점: 정밀하게 구별되는 표현입니다. 기본 네 기준은 단계별 예시도 보여 줍니다.
- 화면의 평균은 현재 학생 필터에 해당하고 현재 평가 기준과 일치하는 완료 분석의 **기준별 점수 합 ÷ 분석 건수**입니다. 대기·실패·업로드는 0점 표본에 넣지 않습니다.
- 발화별 원문, 점수, 원문 인용과 이유를 표시합니다. 새 분석은 해당 단계와 이웃 단계의 차이도 설명하도록 요청합니다. 예전 분석은 이미 저장된 인용 근거를 보여 줍니다.
- 종합 지표는 **기준별 점수 합 ÷ (기준 개수 × 4) × 100**을 반올림합니다. 긴 문장이라는 이유만으로 높게 평가하지 않습니다.

점수는 OpenRouter 의미 모델의 형성평가 관찰 제안입니다. 어휘 개수만 세어서 자동 산출한 정답이나 학생 능력의 확정 평가가 아닙니다. 기존 OpenRouter 모델이 교사의 기준과 원문·직전 문맥을 함께 판단하며, 핵심 표현과 인용은 서버가 현재 원문과 대조합니다. 형태소·품사·구문 분석 통계는 새로 생성하지 않습니다.

## 계정 비밀번호와 종이 배부

비밀번호 칸을 비우고 30명을 등록하면 30명 모두에게 각각 자동 비밀번호를 발급합니다. CSV·Excel에서 비밀번호를 지정하면 지정한 값을 사용합니다. 비밀번호는 활동별 입장 코드가 아닌 **학생 계정의 로그인 비밀번호**입니다.

학생은 같은 비밀번호로 다시 로그인할 수 있지만, 교사가 배정한 클래스의 활동만 정해진 시간에 참여할 수 있습니다. 학년·반·번호·이름도 등록 정보와 맞아야 합니다.

**학생 · 명단 → 발급된 비밀번호 → 학생별 안내 카드 인쇄**를 누릅니다. A4 세로에 두 열로 배치하며 점선을 따라 잘라 배부할 수 있습니다. CSV 저장도 유지합니다. 비밀번호 원문은 발급 직후 화면에만 있고 서버에는 해시만 남으므로, 새로고침 전에 인쇄·저장을 마칩니다. 나중에 원문을 잃어버리면 재발급 후 다시 인쇄합니다. 재발급은 기존 비밀번호와 세션을 폐기합니다.

현재 로컬 주소는 다른 기기의 학생이 접속하는 운영 주소가 아닙니다. 실제 수업용 안내 카드는 Cloudflare에 배포된 주소에서 인쇄합니다.

## 클래스와 참여 대상 배정

**클래스 · 활동 → 새 활동 만들기**에서 참여 대상과 활동 내용을 함께 설정합니다. 같은 클래스에서도 활동마다 참여할 학급·학생을 다르게 운영할 수 있습니다.

1. **관리할 클래스**를 선택합니다. 처음이면 **새 클래스 만들기 → 클래스 만들고 활동 작성**으로 바로 활동 작성 창을 엽니다.
2. **이 활동에 직접 배정** 상태에서 학급 카드를 여러 개 체크하거나, **특정 학생 추가·제외**를 펼쳐 학생을 선택합니다. 특정 학생만 참여시키려면 학급 선택을 비우고 해당 학생을 **이 학생 추가**로 설정합니다. 개별 설정이 학급 선택보다 우선합니다.
3. **참여 가능 N명** 미리보기에서 인원·명단을 확인하고 활동 이름, 단원, 일정, 발화 한도, 평가 기준을 입력합니다. **활동 저장**은 활동과 참여 대상을 함께 저장합니다. 취소·창 닫기는 저장하지 않습니다.
4. 등록 후에는 활동 카드의 **참여 학생 확인·변경**에서 그 활동의 대상만 바꿀 수 있습니다. **활동 수정**에서도 내용과 대상을 함께 수정합니다.

**클래스 기본 참여 대상**은 선택 사항입니다. 자주 사용하는 학급·학생을 기본 대상으로 지정해 둘 수 있습니다. 새 활동의 직접 배정은 처음에 기본 대상을 복사하고, 이후에는 독립적으로 저장합니다. **클래스 기본 대상 불러오기**도 현재 작성 중인 선택만 바꾸며 저장 전에는 서버에 반영하지 않습니다.

**클래스 기본 배정 따르기**를 명시적으로 선택한 활동만 나중의 기본 배정 변경을 함께 따릅니다. 활동에 직접 배정한 대상은 기본 배정이나 다른 활동의 변경에 영향을 받지 않습니다. 기존 활동은 종전의 클래스 기본 배정 상태를 유지하며, 활동별 직접 배정으로 언제든 전환할 수 있습니다. ‘선택 모두 해제’ 후 직접 배정으로 저장하면 그 활동에는 아무도 입장하지 못합니다.

선택한 학급에 나중에 등록되는 학생도 해당 활동의 학급 배정을 따릅니다. 활성 상태로 등록된 학생만 인원에 포함하고, 미등록 학생은 로그인하지 못합니다. 클래스 기본 대상에 없는 학생도 활동에 직접 배정할 수 있습니다. 학급 배정 최대 100개, 개별 설정 최대 500명입니다.

학생 목록·입장·새 발화·업로드·이미지 조작에는 활동별 접근 권한을 적용합니다. 배정을 해제해도 과거 발화·이미지·분석 기록과 교사 화면·백업은 보존합니다. 클래스·활동 삭제 역시 기존 기록을 보존하며 학생 목록에서 숨기는 방식입니다. 백업에는 활동별 배정 방식, 학급, 개별 학생 설정도 포함됩니다.

## 학생 이미지 작업과 전체 기록

1. 문장으로 새 이미지를 만들거나 **기존 이미지 올리기**를 선택합니다. JPEG·PNG·WebP, 4MB 이하, 각 변 4096픽셀 이하입니다. 활동당 업로드 시도 50장까지 보관합니다.
2. 업로드 원본 바이트를 그대로 R2에 저장합니다. 업로드 자체는 발화 한도를 차감하지 않고, 수정 문장을 전송할 때 1회 사용합니다.
3. 올린 이미지가 작업 화면에 보이면 수정할 부분을 말하거나 입력합니다. 수정본은 새 파일로 저장하고 수정 전 이미지와 연결합니다. 원본을 덮어쓰지 않습니다.
4. **이 이미지를 나의 무드보드로 옮기기**로 보관합니다. 보드에서는 개별 이미지 저장, 보관 이미지 ZIP, 이어서 수정을 사용할 수 있습니다.
5. 작업 이미지·업로드 이미지·보드 이미지 우측 상단 X는 **화면에서 제거**합니다. R2 파일과 과거 이력을 지우지 않습니다.
6. **발화 · 이미지 이력**에서 업로드·생성·수정·제거·보관·다시 불러온 시각과 원본 이미지를 확인합니다. 활동 시간 안에는 기록 이미지를 다시 작업 화면으로 불러올 수 있습니다.
7. **기록 내려받기**는 현재 보드에 없는 이미지와 X로 제거한 이미지도 포함합니다. 원본 이미지 파일, 발화·업로드 기록, 이미지 목록·수정 관계, 이미지 변경 이력을 JSON과 ZIP으로 묶습니다. 보드 ZIP은 보드에 보관된 이미지만 포함합니다.

큰 다운로드는 이미지 64MB 단위의 ZIP으로 나누어 각 파일을 저장하도록 안내합니다. 전체 발화와 이미지 작업 이력은 페이지를 이어 읽어 수집합니다. 학생 화면의 발화 목록은 최근 200건, 이미지 이력은 더 보기 방식이며 전체 내려받기에는 전체 기록을 수집합니다.

업로드 본문은 전체 서버에서 최대 4건을 동시에 처리합니다. 동시 요청이 많으면 브라우저가 같은 업로드 번호로 잠시 기다렸다가 다시 시도합니다. 학생별로는 생성·업로드 한 작업만 진행합니다. 원문/업로드 기록을 먼저 D1에 남기고, R2 저장 이후 D1 연결과 작업 이력을 확정합니다. 연결이 끊긴 업로드도 Cron이 저장된 원본을 확인해 복구하거나 실패 기록을 남깁니다.

이력 기능 도입 전에는 이미 저장된 생성·수정 관계를 복원합니다. 과거에 따로 기록하지 않았던 화면 조작 시각을 임의로 만들지는 않습니다. 새 기능 적용 이후의 이미지 조작부터 모두 기록합니다.

## 글 종류와 한글 표현

**글 종류 · 스타일 → 글의 종류 추가**에서 기행문·일기·안내문 등을 추가하고 기본 추천 스타일을 지정합니다. 사용을 끄면 새 선택 메뉴에서 숨깁니다. 기존 이미지·기록은 보존합니다. 학생은 활동 목록으로 돌아오거나 화면을 새로고침하면 변경된 선택 목록을 받습니다.

현재 이미지 모델은 `openai/gpt-image-2`로 고정돼 있습니다. 한글 문구를 요청하면 명령 해석 과정에서 원문을 번역하지 않고 보존하도록 했습니다. 실제 OpenRouter 테스트의 포스터에서 ‘비 오는 날도 즐거워’, ‘상상을 펼쳐요’를 읽을 수 있게 생성한 결과를 확인했습니다. 긴 문장, 작은 글씨, 정확한 배치·자간은 계속 검수가 필요합니다. [공식 이미지 생성 안내의 제한](https://developers.openai.com/api/docs/guides/image-generation#limitations)을 참고하세요.

## 음성 입력이 바로 끝날 때

이전 구현은 `continuous=false`인 단발 인식이었고 종료 때 바로 듣기를 껐습니다. 현재는 연속 인식·중간 인식문·무음 종료 후 제한된 재연결을 사용하며, 직접 종료하거나 최대 5분에 도달하면 멈춥니다. 네트워크·마이크·권한 오류는 계속 재시도하지 않고 구체적으로 안내합니다.

localhost라는 이유만으로 1초 뒤 종료되는 것은 아닙니다. 내장 브라우저나 OS의 음성 인식 서비스, 마이크 권한, 인터넷 연결도 원인이 될 수 있습니다. Chrome·Edge에서 같은 주소를 열어 마이크 권한을 확인하세요. 실제 마이크로 발화하는 하드웨어 검증은 아직 별도이며, 인식 결과 누적·재연결·반복 종료 제한은 자동 테스트로 확인했습니다. [MDN 연속 인식 설명](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/continuous), [MDN 종료 이벤트](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/end_event).


## 무료 플랜 저장 용량

백업·보관 화면에서 이미지·수정본·화면에서 제거한 원본·백업의 저장 예약량과 상한을 확인합니다. 기본 상한은 8GB이며 80%부터 경고합니다. 상한에 도달해도 기존 기록과 파일을 자동 삭제하지 않습니다. 실제 Cloudflare 계정 전체 무료량과 OpenRouter 사용료는 각 서비스에서 확인합니다.
