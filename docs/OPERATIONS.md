# 30명 수업·Cloudflare 무료 플랜 운영 판단

기준일 2026-10-25. Containers와 별도 NLP 서버를 제거했습니다. 정적 화면은 Worker Assets, API·비밀번호 해시·파일 처리는 무료 SQLite Durable Objects, 기록은 D1, 원본 이미지는 R2에 둡니다. 이미지 생성·분석·백업은 Queues로 처리하며 원문은 작업을 큐에 보내기 전에 D1에 확정합니다.

## 동시 접속과 지연

30명 동시 접속과 30장의 즉시 완성은 다릅니다. 운영 큐는 소비자 1개가 배치당 최대 6개 작업을 병렬 처리합니다. 배치 크기 1·소비자 최대 6 설정은 신규 큐가 처음에 한 개씩 처리하다가 약 2분 후에야 동시성을 늘리는 지연이 실제 배포에서 관찰되어 변경했습니다. 현재는 자동 확장을 기다리지 않고 배치 안에서 작업을 병렬 처리하며, 큐 호출 하나에서 모두 완료를 기다린 뒤 개별 메시지를 확인합니다. 모델 지연·OpenRouter 잔액과 속도 제한에 따라 대기할 수 있습니다. 학생별 생성 작업은 하나씩 수락합니다. 같은 요청 번호의 재전송은 기존 작업을 돌려줍니다. 업로드는 전체 4개 본문 처리 슬롯을 사용하며 나머지는 같은 업로드 번호로 다시 시도합니다. 응답 연결이 끊긴 경우에도 같은 번호로 이미 저장됐는지 재확인합니다.

로컬 시험의 30건 처리 시간은 모의 AI 응답을 사용한 값이며 운영 지연과 구별합니다. 운영 시험은 30명이 동시에 제출하고 큐가 최대 6개 작업을 처리한 경우입니다. 모델에 이미지 30개를 동시에 요청한 시험은 아닙니다. 한 차례 수업 규모의 실제 성공 결과이며, 장기 누적 사용량이나 모든 날짜의 응답 시간·언어 정확도를 보장하지 않습니다. 운영 DB·큐·저장소의 계정 사용량은 계속 확인합니다.

## 무료 제공량과 앱 제한

- 배포 전체 하루 발화 수락 상한 300회(한국 시간). 30명 × 10회이며 수업이 여러 개면 합산됩니다. 실패·무시·수정도 수락됐으면 횟수를 사용합니다.
- 이미지·백업 저장 상한 8GB. 원본·수정본·화면에서 제거한 원본·백업 사본을 모두 포함합니다. 저장 전 D1의 단일 조건문과 트리거로 원자적으로 예약하므로 동시 저장이 상한을 넘지 않습니다.
- 저장량은 합계 행에서 읽어 파일 개수에 비례하는 반복 스캔을 피합니다. 불확실한 R2 쓰기 실패는 예약량을 남겨 보수적으로 계산합니다. 과거 백업 manifest는 마이그레이션에서 임시 1MiB로 넣고, 새 파일 저장 전에 R2 실제 크기로 보정합니다.
- 80%부터 교사 백업 화면에 경고. 상한 도달 시 새 파일 저장만 중지하며 로그·원본 자동 삭제 없음. 실제 파일과 메타데이터가 확정되기 전 성공 표시 없음.
- 명단 300명은 25명씩, 비밀번호 재발급은 20명씩 나누어 처리합니다. 여러 학급/500명 개별 배정은 25행씩 묶은 SQL로 저장하며 D1의 요청당 쿼리·바인딩 한도를 고려합니다.
- 매분 Cron은 유지보수 작업 하나만 큐에 보냅니다. 유지보수도 발행 개수·업로드 복구·백업 만료 삭제량을 나누어 처리합니다. Free 큐 메시지 보관은 24시간이며 장기 대기 작업의 상태는 D1에 남아 다시 발행됩니다.
- R2 무료량은 계정 단위입니다. 앱의 8GB 제한은 전용 버킷의 용량 안전장치이며 계정의 다른 버킷·요청량·외부 수동 업로드 비용까지 제한하지는 않습니다. R2 활성화·결제수단 등록이 필요하고 초과량은 과금됩니다. OpenRouter 비용도 별도입니다.

정상적으로 300개 명령의 생성·분석을 각각 큐 작업으로 처리하면 약 1,800 큐 작업(read/write/delete 합계), 매분 유지보수 발행·소비 약 4,320 작업이 기본량입니다. 이는 산술 추정이며 재시도·백업·수업량·다른 앱 사용분은 추가됩니다. 무료 10,000 작업/일에 무조건 맞는다고 보장하지 않습니다.

## 장애 시 보존
