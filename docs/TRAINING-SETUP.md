# 연수생 실행 안내

## 필요한 것

- Node.js 22.20 이상, pnpm 11.25, 소스 복제용 Git 또는 GitHub ZIP.
- OpenRouter API 키와 사용 잔액. 모델 호출료는 별도입니다.
- Docker·WSL·Python·Java·분석 서버 설치는 필요하지 않습니다.

## 1. 먼저 로컬에서 확인

README의 복제 → pnpm install --frozen-lockfile → .dev.vars 설정 → pnpm db:local → pnpm dev 순서로 실행합니다. localhost에서만 확인할 때 Cloudflare 계정이나 결제수단은 필요하지 않습니다. 키·비밀번호 파일이 이미 있으면 복사 명령으로 덮어쓰지 않습니다.

교사 로그인 → 학생 명단 양식 다운로드 → 양식 입력·업로드 → 발급 비밀번호 카드 인쇄 → 클래스·활동 작성 → 참여 학급·개별 학생 선택 → 한국 시간 일정·발화 한도 저장 → 학생 로그인 순서로 확인합니다. 명단은 300명까지 한 번에 선택할 수 있으며 무료 플랜 DB 한도에 맞춰 25명씩 나누어 등록됩니다. 중간 오류 시 완료된 학생의 비밀번호를 보존하고 남은 명단만 다시 등록합니다. 비밀번호 재발급은 20명씩 처리합니다.

## 2. 학생에게 인터넷 주소 제공

Cloudflare Workers Free 계정을 사용합니다. 이미지와 백업을 보관할 R2는 결제수단 등록을 통한 활성화가 필요합니다. R2 무료량 초과는 과금되므로 이 앱 전용 버킷을 만들고 계정 사용량도 확인합니다. Workers Paid 가입과 Containers 배포는 필요하지 않습니다.

README의 D1 생성·자신의 database_id 입력 → R2 버킷·큐 2개 생성 → 원격 DB 마이그레이션 → pnpm deploy → Secrets 2개 설정 순서로 진행합니다. 각 연수생은 자신의 Cloudflare 계정과 OpenRouter 키를 사용합니다. 로컬 학생·이미지를 원격 DB로 자동 복사하지 않습니다.

## 3. 수업 시작 전 확인

교사와 예시 학생 계정으로 활동 배정·일정·한도·실제 이미지 1장과 분석 완료를 확인합니다. 학생끼리 이미지가 공유되지 않는지, 새로고침 후 기록이 남는지, 제거한 이미지도 기록 내려받기에 포함되는지 확인합니다. 음성 입력은 Chrome의 마이크 권한을 허용합니다.

기본 발화 상한은 배포 전체 하루 300회입니다. 30명 × 10회가 이에 해당하며 다른 활동·교사 확인용 요청도 합계에 포함됩니다. 업로드는 발화와 별개로 학생·활동당 최대 50장, 원본 4MB 이하입니다. 보관 용량은 수정본·제거한 원본·백업을 포함해 8GB이며, 한도에 도달하면 새 파일 저장을 중지합니다. 백업 화면에서 사용량을 확인할 수 있습니다.

## 4. 자료 처리

문맥·핵심 표현 분석도 기존 OpenRouter로 통합했습니다. 국내외 연구기관 API로 학생 발화를 추가 전송하지 않습니다. OpenRouter 문자 요청은 data_collection=deny를 사용하며 이미지 요청은 계정의 개인정보 설정에서 자료 수집 정책을 별도로 설정합니다. 학생 발화의 자동 분석은 교사의 관찰을 돕는 제안입니다. 불명확한 반어·이중 부정과 평가 근거는 교사가 검토합니다.

## 5. GitHub에 내 앱 올리기

실제 .dev.vars, 로컬 DB, 이미지, 명단, 발급 비밀번호, output 폴더를 올리지 않습니다. pnpm publish:check는 Git에 포함될 파일만 검사합니다. 이 저장소의 GitHub Actions는 TypeScript·통합 테스트·배포 dry-run을 수행하며 실제 배포 키를 요구하지 않습니다.
