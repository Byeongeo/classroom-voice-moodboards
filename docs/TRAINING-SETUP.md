# 연수생 실행 안내

## 추천: 설치 없이 버튼으로 배포

배포 앱의 /training-guide.html 또는 저장소 public/training-guide.html을 엽니다. 상단의 안내 HTML 다운로드로 파일 한 개를 받아 연수생에게 배부할 수 있습니다. API 키·운영자 비밀번호·입력한 앱 주소는 내려받는 안내에 포함되지 않습니다. Chrome에서 파일을 두 번 클릭해 열어도 동작하며 인터넷 연결은 필요합니다.

1. 안내의 GitHub·Cloudflare 회원가입 버튼으로 각자 계정을 만들고 이메일 인증·로그인을 완료합니다.
2. 이번에 사용할 Cloudflare 계정에서 R2를 활성화합니다. 결제수단과 약관은 본인이 직접 처리합니다. Workers Paid 가입은 필요하지 않습니다.
3. OpenRouter에 가입하고 본인의 키·사용 잔액을 준비합니다. 키는 HTML에 입력하지 않고 Cloudflare의 Secret 입력 칸에만 붙여 넣습니다.
4. HTML에서 32자 관리자 비밀번호를 생성·복사해 비공개 장소에 보관합니다. 브라우저를 닫으면 생성 값은 사라집니다.
5. 내 GitHub에 복제하고 Cloudflare에 배포하기 버튼을 누릅니다. GitHub 연결·저장소 접근 권한을 확인하고 승인합니다. 새 리소스와 두 Secrets 값을 확인한 뒤 Deploy를 누릅니다. 화면 빌드·DB 구조 적용·배포 명령이 저장소에 포함되어 있습니다.
6. 발급된 자신의 workers.dev 주소를 안내에 붙여 넣어 교사 화면을 엽니다. 자신의 관리자 비밀번호로 로그인하고 예시 학생·활동을 먼저 확인합니다.

다른 계정에서의 실제 회원가입·권한 승인·R2 계약을 HTML이 대신 완료하지는 않습니다. 완료 체크는 사용자가 직접 표시합니다. 생성 비밀번호와 키를 localStorage·GitHub·안내 HTML에 저장하지 않습니다. 버튼 복제 과정에는 Cloudflare의 GitHub 연결과 해당 계정의 리소스 준비가 필요합니다. 연결 승인이 제한된 기관 계정은 아래 로컬/CLI 방법을 사용하거나 계정 관리자와 확인합니다.

## 관리자 비밀번호 변경

운영 앱: Cloudflare → Workers & Pages → 자신의 앱 → Settings → Variables and Secrets → TEACHER_PASSWORD를 Secret으로 편집하고 적용합니다. 24~128자를 사용합니다. 현재 Secret 원문은 Cloudflare에서 다시 읽어 주지 않습니다. 잊어버렸다면 새 값으로 설정합니다. 관리자 아이디나 로그인 번호는 없으며 관리자 비밀번호만 사용합니다. 로컬 앱: .dev.vars의 TEACHER_PASSWORD 변경 후 로컬 서버를 재시작합니다. 로컬과 운영 값은 자동 동기화되지 않습니다.

## 필요한 것

- Node.js 22.20 이상, pnpm 11.25, 소스 복제용 Git 또는 GitHub ZIP.
- OpenRouter API 키와 사용 잔액. 모델 호출료는 별도입니다.
- Docker·WSL·Python·Java·분석 서버 설치는 필요하지 않습니다.

## 1. 먼저 로컬에서 확인

README의 복제 → pnpm install --frozen-lockfile → .dev.vars 설정 → pnpm db:local → pnpm dev 순서로 실행합니다. localhost에서만 확인할 때 Cloudflare 계정이나 결제수단은 필요하지 않습니다. 키·비밀번호 파일이 이미 있으면 복사 명령으로 덮어쓰지 않습니다.

교사 로그인 → 학생 명단 양식 다운로드 → 양식 입력·업로드 → 발급 비밀번호 카드 인쇄 → 클래스·활동 작성 → 참여 학급·개별 학생 선택 → 한국 시간 일정·발화 한도 저장 → 학생 로그인 순서로 확인합니다. 명단은 300명까지 한 번에 선택할 수 있으며 무료 플랜 DB 한도에 맞춰 25명씩 나누어 등록됩니다. 중간 오류 시 완료된 학생의 비밀번호를 보존하고 남은 명단만 다시 등록합니다. 비밀번호 재발급은 20명씩 처리합니다.

## 2. 학생에게 인터넷 주소 제공

Cloudflare Workers Free 계정을 사용합니다. 이미지와 백업을 보관할 R2는 결제수단 등록을 통한 활성화가 필요합니다. R2 무료량 초과는 과금되므로 이 앱 전용 버킷을 만들고 계정 사용량도 확인합니다. Workers Paid 가입과 Containers 배포는 필요하지 않습니다.

README의 D1 생성 → pnpm cloud:config와 자신의 database_id로 운영 설정 생성 → R2 버킷·큐 2개 생성 → 원격 DB 마이그레이션 → pnpm deploy → Secrets 2개 설정 순서로 진행합니다. 운영 설정은 Git에서 제외한 output/wrangler.production.jsonc에 두고 로컬 DB 설정은 보존합니다. 각 연수생은 자신의 Cloudflare 계정과 OpenRouter 키를 사용합니다. 로컬 학생·이미지를 원격 DB로 자동 복사하지 않습니다.

## 3. 수업 시작 전 확인

교사와 예시 학생 계정으로 활동 배정·일정·한도·실제 이미지 1장과 분석 완료를 확인합니다. 학생끼리 이미지가 공유되지 않는지, 새로고침 후 기록이 남는지, 제거한 이미지도 기록 내려받기에 포함되는지 확인합니다. 음성 입력은 Chrome의 마이크 권한을 허용합니다.

기본 발화 상한은 배포 전체 하루 300회입니다. 30명 × 10회가 이에 해당하며 다른 활동·교사 확인용 요청도 합계에 포함됩니다. 업로드는 발화와 별개로 학생·활동당 최대 50장, 원본 4MB 이하입니다. 보관 용량은 수정본·제거한 원본·백업을 포함해 8GB이며, 한도에 도달하면 새 파일 저장을 중지합니다. 백업 화면에서 사용량을 확인할 수 있습니다.

## 4. 자료 처리

문맥·핵심 표현 분석도 기존 OpenRouter로 통합했습니다. 국내외 연구기관 API로 학생 발화를 추가 전송하지 않습니다. OpenRouter 문자 요청은 data_collection=deny를 사용하며 이미지 요청은 계정의 개인정보 설정에서 자료 수집 정책을 별도로 설정합니다. 학생 발화의 자동 분석은 교사의 관찰을 돕는 제안입니다. 불명확한 반어·이중 부정과 평가 근거는 교사가 검토합니다.

## 5. GitHub에 내 앱 올리기

실제 .dev.vars, 로컬 DB, 이미지, 명단, 발급 비밀번호, output 폴더를 올리지 않습니다. pnpm publish:check는 Git에 포함될 파일만 검사합니다. 이 저장소의 GitHub Actions는 TypeScript·통합 테스트·배포 dry-run을 수행하며 실제 배포 키를 요구하지 않습니다.
