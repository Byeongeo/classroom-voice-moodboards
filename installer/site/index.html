01 · 시작

Cloudflare 계정이 있나요?

계정이 있어요 계정이 없어요

이미 쓰는 계정으로 로그인해요

Cloudflare에 로그인하고, 여러 계정이 보이면 수업용 앱을 둘 계정을 확인하세요. 이 설치 탭을 열어 둔 채 다음 단계로 내려오세요.

Cloudflare 로그인 열기 ↗

가입하고 이메일을 확인해요

  1. Cloudflare 가입 열기를 누릅니다. 새 탭에서 이메일과 비밀번호를 입력하고 Sign up 또는 Create account를 누릅니다. 화면에서 보안 확인을 요청하면 마칩니다.
  2. 이메일 받은편지함에서 Cloudflare가 보낸 인증 메일을 열고 Verify email 또는 Verify your email address를 누릅니다. 메일이 안 보이면 스팸함도 확인하세요.
  3. 대시보드 열기를 누르고 방금 만든 이메일로 로그인합니다. Add a domain 화면이 나오면 Account home으로 이동하세요. 이 앱에는 구입한 도메인이 필요 없습니다.
  4. 대시보드에서 본인 계정이 보이면 이 설치 탭으로 돌아와 02 준비부터 진행하세요.

02 · 준비

이미지 저장소와 OpenRouter 키를 준비해요

R2 이미지 저장소

R2 열기를 누르고 앱을 설치할 계정을 선택하세요. Create bucket이 보이면 준비된 상태입니다. 처음이라면 Add R2 subscription을 눌러 요금과 결제수단 화면을 직접 확인하고 활성화합니다. 버킷은 설치기가 만듭니다.

R2 열기 ↗

OpenRouter 키

OpenRouter 키 발급을 열어 로그인하고, Create Key를 눌러 키를 만드세요. 이름은 교실 앱처럼 알아보기 쉽게 적고, 키를 복사해 03의 입력란에 붙여 넣으세요.

OpenRouter 키 발급 ↗

Workers Free로 설치합니다. R2 활성화 시 결제수단이 필요할 수 있으며 무료 제공량을 넘기면 요금이 발생합니다. OpenRouter 이미지 생성과 문장 분석 비용은 별도입니다.

03 · 설치

설치 권한을 확인하고 앱을 만들어요

1. 임시 설치 토큰 발급

토큰 발급 양식 열기를 누릅니다. 설치에 필요한 항목을 미리 선택해 둔 Cloudflare 화면이 열립니다.

  1. Permissions에서 Account Settings 읽기와 Workers Scripts · Workers R2 Storage · D1 · Queues 편집 권한이 보이는지 확인하세요.
  2. Account Resources는 Include → Specific account로 바꾸고 앱을 설치할 계정 하나를 선택하세요. TTL에서 가능하면 오늘 또는 연수 종료 시간까지로 만료를 정하세요.
  3. Continue to summary → Create Token을 누릅니다. 한 번 표시되는 토큰을 Copy하고 이 페이지의 Cloudflare 설치 토큰 칸에 붙여 넣으세요.
토큰 발급 양식 열기 ↗

이번에 만든 설치 토큰을 사용하세요. Cloudflare 로그인 비밀번호나 Global API Key는 입력하지 않습니다. 설치 토큰은 저장하지 않습니다.

2. 설치에 필요한 값 입력

4~128자로 정하고 따로 기억해 두세요. 이 비밀번호는 설치 후 교사 로그인에 씁니다.

선택한 계정에 새 앱과 저장소를 만듭니다. 계정의 첫 Workers 앱이면 무료 workers.dev 주소도 등록합니다. OpenRouter 키와 교사 비밀번호는 내 앱의 Cloudflare Secrets에 등록됩니다.

04 · 첫 접속

내 교실 앱이 만들어졌어요

내 교사 화면 열기 ↗ 학생 화면 열기 ↗

교사 화면에서 방금 정한 비밀번호로 로그인하세요. 가상 학생 한 명을 등록하고 활동과 이미지 한 장을 확인하면 학생들에게 주소를 나눠 줄 수 있습니다.

설치를 마쳤다면 Cloudflare의 API Tokens ↗에서 이번 설치 토큰을 삭제하거나 만료되도록 두세요.

기존 GitHub 배포 방법도 선생님 배포 안내에서 이용할 수 있습니다.
