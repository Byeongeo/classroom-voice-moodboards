STEP 02 · 이미지 보관 준비

이미지를 저장할 R2를 켜 주세요.

R2는 학생이 만든 이미지와 백업을 담는 보관함입니다. 지금은 기능만 켜고, 실제 보관함 생성은 5단계에서 자동으로 진행합니다.

Cloudflare R2 화면 열기 ↗
  1. 계정이 여러 개라면 이번 앱을 배포할 계정을 선택합니다.
  2. 왼쪽의 Storage & databases → R2 Object Storage → Overview로 이동합니다.
  3. 처음이라면 결제수단 등록과 Add R2 subscription to my account 절차를 직접 완료합니다.
  4. Create bucket 버튼이나 버킷 목록이 보이면 준비된 상태입니다. 이 단계에서 버킷을 직접 만들 필요는 없습니다.
비용을 먼저 알아두세요. Workers Paid 가입은 필요하지 않습니다. R2 Standard에는 월 10GB-month 등의 무료 제공량이 있지만, 활성화에 결제수단이 필요하고 무료량을 넘으면 과금됩니다. 이 앱은 이미지·수정본·백업 합계 8GB에서 새 저장을 멈추지만, 계정 전체의 청구 상한은 아닙니다. 공식 요금 확인 ↗
STEP 03 · 이미지와 문맥 분석

OpenRouter API 키를 준비해요.

API 키는 앱이 AI를 사용할 때 제시하는 개인 열쇠입니다. 이 열쇠로 이미지 생성과 학생 발화 분석을 요청합니다.

OpenRouter 가입·키 발급 화면 ↗사용 잔액 확인 ↗
  1. 처음이라면 OpenRouter에서 회원가입·로그인을 완료합니다.
  2. 키 발급 화면의 Create Key를 눌러 알아보기 쉬운 이름을 적습니다. 가능하면 연수용 사용 한도를 정합니다.
  3. 발급된 키를 복사해 본인만 볼 수 있는 곳에 보관합니다. 이 안내 HTML에는 입력하지 않습니다.
  4. 5단계 Cloudflare 배포 화면의 OPENROUTER_API_KEY 칸에 붙여 넣습니다.
Cloudflare 무료 플랜과 AI 사용료는 별개입니다. OpenRouter에 잔액이 없거나 사용 한도를 넘으면 이미지가 만들어지지 않습니다. 키를 강사·다른 연수생에게 보내거나 GitHub 파일에 적지 않습니다.
학생 발화의 자료 수집 설정도 확인하고 싶어요.

OpenRouter의 개인정보 설정에서 자료 수집 정책을 확인합니다. 앱의 문자 분석 요청에는 자료 수집을 허용하지 않는 제공자를 선택하는 옵션을 적용했으며 이미지 요청은 계정 설정을 별도로 확인해야 합니다. 모든 제공자의 무보관·국내 처리를 보장하는 설정은 아닙니다.

STEP 04 · 교사 로그인 준비

내 앱의 관리자 비밀번호를 만들어요.

이 비밀번호로 학생 명단·활동·수업 기록을 관리합니다. 학생에게 배부하는 비밀번호와는 다릅니다.

비밀번호는 이 화면의 메모리에만 있습니다. 페이지를 닫거나 새로고침하기 전에 본인의 비밀번호 관리 도구 등에 따로 보관하세요. 안내 HTML 다운로드와 인쇄에는 포함하지 않습니다.

  1. 위 버튼으로 비밀번호를 만들고 비밀번호 복사를 누릅니다.
  2. 본인만 볼 수 있는 곳에 보관합니다.
  3. 5단계 Cloudflare 배포 화면의 TEACHER_PASSWORD 칸에 그대로 붙여 넣습니다.
TEACHER_PASSWORD
나중에 관리자 비밀번호는 어디서 바꾸나요?

Cloudflare → Workers & Pages → 내 앱 → Settings → Variables and Secrets → TEACHER_PASSWORD에서 Secret 값을 편집하고 Deploy/Save로 적용합니다. 현재 설정된 비밀 값은 다시 표시되지 않으므로 잊어버렸다면 새 값으로 설정합니다. 비밀번호는 24~128자입니다.

PC에서 로컬로 실행할 때는 앱 폴더의 .dev.vars에 있는 TEACHER_PASSWORD를 변경하고 로컬 서버를 다시 시작합니다. 로컬 값을 바꿔도 배포된 앱의 비밀번호가 자동으로 바뀌지는 않습니다.

STEP 05 · 내 앱 만들기

버튼을 눌러 복제와 배포를 시작해요.

Cloudflare 공식 배포 화면이 열립니다. 내 GitHub 계정에 소스를 복제하고, 필요한 저장소와 앱을 준비합니다. 이 안내 페이지에 API 키를 입력하지 않습니다.

내 GitHub에 복제하고 Cloudflare에 배포하기 ↗
내 GitHub에 복제 → D1 · R2 · 큐 준비 → DB 구조 적용 → 앱 배포
처음에 Cloudflare 계정 선택 화면이 나타나면 2단계에서 R2를 켠 계정을 선택하세요. 계정 이름을 확인한 뒤 이어서 진행합니다.
  1. GitHub 연결을 요청하면 본인의 계정을 선택하고, 표시된 저장소 접근 권한을 확인한 뒤 승인합니다. 이 권한으로 Cloudflare가 내 복제본을 읽고 배포합니다.
  2. 저장소 이름·앱 이름은 처음이라면 기본값을 사용합니다. 이미 같은 이름이 있다면 이름 끝에 -2 등을 붙입니다.
  3. 리소스 설정에서 새 D1·R2·큐를 준비합니다. 다른 수업 앱의 기존 DB를 선택하지 말고 이번 앱 전용 새 리소스를 사용합니다. R2는 앞 단계와 같은 계정이어야 합니다.
  4. Secrets / Variables에서 아래 두 값을 반드시 본인의 값으로 입력합니다.
화면에 나오는 이름붙여 넣을 값
OPENROUTER_API_KEY3단계에서 발급한 내 OpenRouter API 키
TEACHER_PASSWORD4단계에서 만들고 보관한 내 관리자 비밀번호
  1. Build command는 pnpm run build, Deploy command는 pnpm run deploy가 자동으로 채워지는지 확인합니다. 다른 값이라면 아래 버튼으로 복사해 넣습니다.
  2. Deploy를 누르고 완료될 때까지 기다립니다. 창을 닫지 말고 오류가 나면 아래 도움말을 확인합니다.
  3. 성공하면 표시되는 https://앱이름.내계정.workers.dev 주소를 복사하고 이 안내의 6단계로 돌아옵니다.
“클론”은 무엇이고, 내 PC에도 받아야 하나요?

클론은 앱 소스를 복사한다는 뜻입니다. 위 배포 버튼은 내 GitHub에 복제본을 만들고 Cloudflare 서버에서 빌드하므로 PC에 Git·Node.js·Docker를 설치할 필요가 없습니다. 코드를 직접 고치는 연수에서는 나중에 PC로 복제할 수 있습니다.

원본 GitHub 살펴보기 ↗소스 ZIP 다운로드 ↗
배포가 멈추거나 빨간 오류가 보여요.
  • R2 활성화 오류: 2단계에서 이번 배포 계정의 R2가 켜져 있는지 확인한 뒤 Retry/다시 배포를 누릅니다.
  • 같은 이름이 이미 있음: 새 저장소·앱·리소스 이름을 선택합니다. 기존 DB나 버킷을 지우지 않습니다.
  • DB 테이블을 찾을 수 없음: Deploy command가 pnpm run deploy인지 확인합니다. 이 명령이 DB 준비와 배포를 함께 합니다.
  • 권한 부족: 사용한 계정과 GitHub 연결·리소스 권한을 확인합니다. 오류 메시지를 강사와 함께 확인하고 API 키나 비밀번호는 보내지 않습니다.

STEP 06 · 첫 수업 준비

내 주소로 접속해 교실을 열어요.

아래에 Cloudflare에서 복사한 본인의 앱 주소를 붙여 넣습니다. 강사의 주소가 아니라 내 계정에 배포된 주소를 사용해 주세요.

  1. 내 관리자 페이지 열기를 누르고 4단계의 비밀번호로 로그인합니다. 별도의 관리자 아이디나 번호는 없습니다.
  2. 학생 · 명단에서 Excel/CSV 양식을 내려받아 학생 정보를 입력하고 업로드합니다. 처음에는 가상의 학생 한 명으로 확인해 보세요.
  3. 발급된 학생 비밀번호는 새로고침 전에 안내 카드 인쇄나 CSV 저장으로 보관합니다.
  4. 클래스와 활동을 만들고 참여할 학급·학생, 시작·종료 시간, 발화 횟수를 정합니다.
  5. 학생 계정으로 로그인해 배정된 활동과 이미지 한 장을 확인합니다. 마이크 입력은 Chrome에서 권한을 허용합니다.
  6. 교사 화면의 발화 기록·점수 근거·백업을 확인하고 학생들에게 주소와 개인 비밀번호를 배부합니다.
학생이 이미지를 X로 제거해도 원본과 작업 이력은 남습니다. 학생 명단과 실제 발화를 GitHub에 올리지 않습니다. 자동 분석의 불명확한 반어·이중 부정과 평가 근거는 교사가 확인합니다.
관리자 비밀번호가 맞지 않거나 이미지가 생성되지 않아요.

관리자 비밀번호는 이 안내의 예시가 아니라 본인이 Cloudflare에 넣은 TEACHER_PASSWORD입니다. 잊어버렸다면 Cloudflare의 내 앱 → Settings → Variables and Secrets에서 새 값으로 설정합니다. OPENROUTER_API_KEY도 같은 위치의 Secret인지 확인하고, OpenRouter 잔액·키 사용 한도를 확인합니다. 두 값 모두 공개 환경변수나 GitHub 소스에 넣지 않습니다.

이 파일은 혼자 열어도 동작하는 연수 안내입니다. 가입·본인 인증·권한 승인·결제수단 등록은 각 서비스의 공식 화면에서 본인이 진행합니다. 버튼을 누른 것만으로 가입이나 배포가 완료된 것으로 표시하지 않습니다.
